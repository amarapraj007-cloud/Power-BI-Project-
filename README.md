# Power-BI-Project-
Global University Ranking Analysis – Power BI Dashboard Project

This project focuses on analyzing global university ranking data using Python and Power BI to create interactive and insightful dashboards. The main objective is to help students and academic stakeholders better understand university rankings and the key factors influencing them, such as academic reputation, employer reputation, faculty-student ratio, and international diversity.

The project includes data cleaning and preprocessing in Python (Jupyter Notebook), exploratory data analysis, and the development of dynamic Power BI dashboards with filters and KPIs for better visualization and comparison of universities across different countries and performance metrics.

Through this analysis, the project provides meaningful insights into global ranking trends, top-performing universities, and country-wise educational performance while demonstrating a real-world data analytics workflow and data-driven decision-making process.
